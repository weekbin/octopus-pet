# Octopus Desktop Pet

A coral-pink octopus desktop pet for mcode (and any agent-plugins.org v1.0.0 conformant client).

## What
- 常驻 macOS 桌面, 透明 200×200 窗口
- 14 场景自动轮转 (假装很忙 / 再熬一会 / 我裂开了 / ...)
- 跟 mcode 集成: 章鱼随 mcode 启动自动 spawn
- mcode Agent 可调章鱼 (切场景 / 弹气泡 / 查状态 / 摸头)

## Spec
Conforms to [agent-plugins.org v1.0.0](https://agent-plugins.org/specification).
