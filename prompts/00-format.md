# V2 动作 Prompt 段落格式 (Section Format Spec)

> **目的**: 任何 V2 动作的 prompt 必须严格按这个**段落格式**组装。段落结构 = 4 段 (固定),每段内部子结构 = 5 元素 (起始/动作/细节/⚠️/空间)。
> **这是格式规范**,**不是 V2 14 动作的具体内容**。具体动作内容由用户引导,在 `prompts/0X-xxx.md` 文件里按这个格式填。
> **配套**: `docs/v2-pipeline.md` (Step 3 用这个格式分解动作) + `docs/action-prompt-methodology.md` (方法论理论) + `prompts/01-example-pretend-busy.md` (格式应用示范)

---

## 段落总览 (4 段固定)

```
[Section 1] 通用前缀 (Universal Prefix)         — 16 项约束, 每动作必加
[Section 2] 动作概述 (Action Overview)          — 1-2 句, 强调原地
[Section 3] 按秒分割画面 (Per-Second Breakdown) — 3-5 段, 每段 5 元素
[Section 4] 动作结束后状态 (Post-action State)  — 固定模板, 列残留物体
```

| 段 | 必加 | 子结构 | 字数预估 | 关键产出 |
|----|------|--------|----------|----------|
| 1 通用前缀 | ✅ | 16 项约束 (见下) | ~300 字 | 视觉/物理一致 |
| 2 动作概述 | ✅ | 1-2 句 | ~50-100 字 | 核心元素 + 强调"原地" |
| 3 按秒分割 | ✅ | 3-5 段, 每段 5 元素 | ~600-1000 字 | 时间戳 + 比例 + ⚠️ 强调 |
| 4 动作结束 | ✅ | 固定模板 + 物体清单 | ~80 字 | 恢复 + 残留确认 |

**总字数**: ~1100-1500 字 / 1 个 prompt (10s 动作)

---

## Section 1: 通用前缀 (Universal Prefix)

**作用**: 保证 14 个视频之间**视觉一致** + **物理安全**。**每个 prompt 都必须**加这一段,内容完全相同 (用复制粘贴)。

**V2.1 章鱼版完整内容**:

```
> 【绝对空间与边界约束】
> 视频比例 16:9, 背景必须为纯粹的绿幕色 (标准 Chroma Key Green, 颜色严格统一为 #00FF00), 无任何阴影、杂物、渐变或边框, 背景本身即为单一纯色块。
> 章鱼位置与大小强制固定: V2.1 章鱼标准 3/4 跪坐姿态, 头顶 (含 2 个圆耳小凸起) 处于画幅垂直方向约 20% 位置, 触手触地点 (前向跪坐的 8 条触手尖接地) 处于画幅垂直方向约 85% 位置, 身体最左和最右边缘处于画幅水平方向约 25% 和 75% 位置。不同视频之间的人物大小、位置、比例必须完全一致, 不允许有任何偏差。
> 章鱼周围缓冲区 (防裁切): 头顶 (含圆耳小凸起) 距画幅顶边至少保留 15% 画幅高度的绿色空间, 触手触地点距画幅底边至少保留 10% 画幅高度的绿色空间, 身体左右两侧距画幅边缘至少保留 10% 画幅宽度的绿色空间。
> 绝对禁止出现任何身体部位 (尤其是顶部的圆耳小凸起、底部的触手尖与吸盘、整体身体轮廓) 超出画幅边缘、触碰画幅底边或被裁剪的情况。动作全程必须在画幅内部完成。
> 章鱼 8 条触手落点 (前向跪坐的 8 个触手触地点) 形成的中心坐标恒定为屏幕正中央, 全部 8 个触地点不发生 X 轴或 Y 轴平移位移。只允许轴心旋转、原地跳跃、触手微动 (触手尖上下抬 ≤ 5% 画幅高度, 触手整体微曲 ≤ 10°)。
> 所有视频必须以参考图 (V2.1 standard-char-1x1.png) 的标准 3/4 跪坐姿态为第一起始帧, 并在视频最后一秒 (第 10 秒结束时) 彻底恢复到与第一帧完全一致的标准 3/4 跪坐姿态。
> 不同视频之间的绿色背景色值必须完全一致, 不允许有色差。
```

**16 项约束清单** (用于设计 prompt 时心里默念):

| # | 约束 | 关键数字 |
|---|------|----------|
| 1 | 比例 | 16:9 |
| 2 | 背景色 | `#00FF00` 严格统一 |
| 3 | 头顶 Y 位置 | ~20% 画幅高度 |
| 4 | 触手触地点 Y 位置 | ~85% 画幅高度 |
| 5 | 左右 X 位置 | 25% - 75% |
| 6 | 头顶缓冲区 | ≥15% 画幅高度 |
| 7 | 触地点缓冲区 | ≥10% 画幅高度 |
| 8 | 左右缓冲区 | ≥10% 画幅宽度 |
| 9 | 禁止出界 (头部/触手/身体) | 必须 |
| 10 | 触手锁死原点 (8 触地点不位移) | 必须 |
| 11 | 仅允许轴心旋转/原地跳跃/触手微动 | 触手尖 ≤5% 画幅高度 / 触手曲 ≤10° |
| 12 | 第一帧 = 参考图 (V2.1 standard-char-1x1.png) | 必须 |
| 13 | 最后一帧 = 第一帧 | 必须 |
| 14 | 14 视频之间背景色值色差 = 0 | 必须 |
| 15 | 触手尖 / 圆耳小凸起 不触顶不触底 | 必须 |
| 16 | 整体身体轮廓 不出界 | 必须 |

## Section 2: 动作概述 (Action Overview)

**作用**: 1-2 句话说清楚**这是什么动作**,**核心元素是什么**,**强调"原地"**。

**子结构 (3 必含)**:
1. 这是什么动作 (e.g. "假装很忙地敲键盘")
2. 核心元素清单 (变出什么 / 做什么 / 消失什么)
3. 强调"原地" + "触手锚定原点" + "全程不位移"

**格式模板**:
```
## [动作名 (中文/英文)]

**动作概述**

Q版珊瑚粉章鱼 [1-2 句话], [核心元素: 变出 X / 做 Y / 消失 Z], [强调"原地" + "触手锚定原点" + "全程不位移"]。
```

**字数**: 50-100 字

**好例子**:
> Q版珊瑚粉章鱼原地 3/4 跪坐, 凭空变出键盘和桌面, 触手快速敲击键盘, 表情专注。键盘在动作结束后消失, 恢复标准 3/4 跪坐。无位移, 无切边, 全身结构完整保留在画面中央, 不出界。

**坏例子 (避免)**:
> ❌ "章鱼在敲键盘" — 太空泛, 没核心元素, 没强调"原地"

## Section 3: 按秒分割画面 (Per-Second Breakdown)

**作用**: 把 10 秒动作**精确拆解**为 3-5 段,每段 1.5-3.5s,每段含 5 个元素。

### 段数 / 时长规范

| 段数 | 总时长 | 适合场景 |
|------|--------|----------|
| 3 段 | ~7s (短) | 简单动作 (眨眼 / 呼吸 / 单表情) |
| 4 段 | ~9s | 中等 (挥触手 / 点头 / 触手动) |
| 5 段 | ~10s | 复杂 (变物 + 使用 + 消失) |
| **4-5 段** | **10s** | **默认** |

### 段标题 (可选, 帮助阅读)

`X~Y秒 (阶段名):` — 用动词或动作描述, 如 `0~2秒 (变出键盘)` / `4~6.5秒 (敲键盘)`。

### 每段 5 元素 (必含)

| # | 元素 | 作用 | 例子 |
|---|------|------|------|
| 1 | **起始状态** | 接续上段 / 第一帧 | "标准 3/4 跪坐 / 触手已举起键盘 / 表情专注" |
| 2 | **具体动作** | 这段做啥 | "触手尖在键盘上快速抬起落下 / 头部微微前倾" |
| 3 | **关键细节** | 比例 / 位置 / 表情 | "触手尖上下幅度 ≤ 3% 画幅高度 / 表情专注 / 微微腮红" |
| 4 | **⚠️ 强调** | 物理 / 空间 / 防穿模 | "⚠️ 强调: 触手尖始终距键盘 ≤ 2% 画幅高度, 不飞离" |
| 5 | **空间坐标** | 数字化位置 | "键盘占画幅宽度 30% / 居中 / 距画幅底边 5% 绿色空间" |

### 格式模板

```
**按秒分割画面**

- 0~2秒 (阶段名):
  起始状态: [...]
  具体动作: [触手做什么 / 表情变化 / 物体出现消失]。
  关键细节: [比例 / 位置 / 表情]。
  ⚠️ 强调: [出界风险 / 比例 / 物理 / 缓冲]。
  空间坐标: [头顶 30% 位置 / 画幅宽度 8%-10% 等具体数字]。

- 2~4秒 (阶段名):
  [...同上结构, 每段 1.5-3.5 秒...]
```

### ⚠️ 强调的常见模式

| 类别 | 模板 |
|------|------|
| 防出界 | "⚠️ 强调: [部位] 距画幅[边] ≥ [N]% 绿色空间" |
| 防穿模 | "⚠️ 强调: [部位] 不与[其他部位/物体]重叠超过瞬间" |
| 比例约束 | "⚠️ 强调: [物体] 比例 Q 版, 不超过触手范围" |
| 物理合理 | "⚠️ 强调: [物体] 不飞溅 / 不洒出 / 不落地" |
| 数字约束 | "⚠️ 强调: [动作幅度] ≤ [N]° / [N]% 画幅高度" |
| 与上段连贯 | "⚠️ 强调: 与前段[动作]连贯, 不出现瞬移或穿模" |

### 比例/空间词汇 (常用)

| 类别 | 词汇 |
|------|------|
| 画幅空间 | 距画幅顶/底/左/右 [N]% 绿色空间 |
| 物品大小 | 直径约 [N]% 画幅宽度 / 高度约 [N]% 画幅高度 |
| 相对比例 | 约触手尖 [N] 倍 / 约人物手掌 [N] 倍 |
| 表情幅度 | 嘴角上扬 [N]° / 眼睛眯成弯月 [N]% 闭合 |
| 移动幅度 | 身体倾斜 ≤ [N]° / 轴心旋转 ≤ [N]° |
| 跳跃高度 | 跳跃高度 ≤ 画幅高度的 [N]% |
| 频次节奏 | 眨眼每隔 [N] 秒 / 喘息每 [N] 秒 [N] 次 |

## Section 4: 动作结束后状态 (Post-action State)

**作用**: 固定模板,确认**所有变出的物体都消散** + **角色回到第一帧**。

**V2.1 章鱼版模板** (固定):

```
**动作结束后状态**

最终帧: 与参考图 (V2.1 standard-char-1x1.png) 标准 3/4 跪坐姿态完全一致——8 触手自然前向跪坐, 触手尖稳定接地, 头顶 2 个圆耳小凸起柔顺向上, 双眼全睁, 表情温和, 微微腮红。**无 [变出的物体清单] 残留**。
```

**填写说明**:
- `8 触手自然前向跪坐` — V2 角色固定描述
- `触手尖稳定接地` — 强调"原地" 约束
- `头顶 2 个圆耳小凸起柔顺向上` — 章鱼头顶装饰 (不是呆毛)
- `双眼全睁, 表情温和, 微微腮红` — 表情恢复
- `**无 [变出的物体清单] 残留**` — 列所有消失物体,**省略"无"也算违规**

**物体清单写法** (必须列出):

| 动作 | 残留物体清单 |
|------|---------------|
| idle-breathing | (无变出物体) → "**无任何动作残留**" |
| pretend-busy | 变出键盘 → "**无键盘残留**" |
| treat-milk-tea | 变出奶茶杯 → "**无奶茶杯残留**" |
| 通式 | 每变出一个物体,**动作结束后**段必须显式说"无 [X] 残留" |

## 完整 prompt 组装示例 (段落框架)

```markdown
[Section 1: 通用前缀]
> 【绝对空间与边界约束】
> 视频比例 16:9, ...
> 章鱼 8 条触手落点 ...
> 不同视频之间的绿色背景色值 ...

---

[Section 2: 动作概述]
## 假装很忙 (Pretend Busy)

**动作概述**

Q版珊瑚粉章鱼 [1-2 句], [核心元素], 强调"原地" + "触手锚定原点"。

---

[Section 3: 按秒分割画面]
**按秒分割画面**

- 0~2秒 (变出键盘):
  起始状态: 标准 3/4 跪坐, 8 触手前向触地。
  具体动作: 触手尖从身前凭空变出键盘和桌面。
  关键细节: 键盘居中, 表情从平静转为专注。
  ⚠️ 强调: 键盘距画幅底边 ≥ 5% 绿色空间, 不超 30% 画幅宽度。
  空间坐标: 键盘画幅宽度 30%, 居中, 距画幅底边 5% 绿色空间。

- 2~4秒 (触手敲击):
  [...同上结构, 4-5 元素齐全...]

- 4~6.5秒 (表情变化):
  [...同上...]

- 6.5~8.5秒 (收回):
  [...同上...]

- 8.5~10秒 (键盘消失 + 恢复):
  键盘以魔术般的动作凭空消散。触手自然落回前向触地。
  圆耳小凸起恢复柔顺, 表情恢复温和。
  第 10 秒结束时彻底恢复为标准 3/4 跪坐姿态。

---

[Section 4: 动作结束后状态]
**动作结束后状态**

最终帧: 与参考图 (V2.1 standard-char-1x1.png) 标准 3/4 跪坐姿态完全一致——8 触手自然前向跪坐, 触手尖稳定接地, 头顶 2 个圆耳小凸起柔顺向上, 双眼全睁, 表情温和, 微微腮红。**无键盘残留**。
```

## 检查清单 (提交前)

- [ ] 4 段齐全,顺序正确 (通用前缀 → 概述 → 按秒 → 状态)
- [ ] 通用前缀**用章鱼版**(不是 dsh-pet 人物版)
- [ ] 动作概述 1-2 句, 强调"原地"
- [ ] 3-5 段时间戳连续无空隙, 总和 = 10s
- [ ] 每段 5 元素齐全 (起始/动作/细节/⚠️/空间)
- [ ] 每段至少 1 个 ⚠️ 强调
- [ ] 每段至少 1 个数字化比例
- [ ] 段尾物体凭空消散有明确说明
- [ ] 动作结束后状态列举所有残留物体
- [ ] **没有 dsh-pet 角色专属词** (双手/双脚/呆毛/裙摆/鲸鱼尾巴/鞋/围裙)
- [ ] 与 V2.1 标准图 (3/4 跪坐) 姿态一致
