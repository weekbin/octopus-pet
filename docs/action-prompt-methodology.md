# Action Prompt Methodology — 借鉴 dsh-pet 提取的方法论

> **核心定位**: **本文件是从 dsh-pet 提示词中提炼的方法论**,**不是 V2 14 动作的具体内容**。
> **dsh-pet 的提示词是学习材料** (见 [原始链接](https://github.com/PC2005-cloud/dsh-pet/blob/main/prompts/%E6%A1%8C%E9%9D%A2%E5%AE%A0%E7%89%A9%2010%20%E7%A7%92%E5%8A%A8%E4%BD%9C%E6%8F%90%E7%A4%BA%E8%AF%8D.md)),**不能直接抄** — dsh-pet 是 Q版蓝发女仆,V2 是珊瑚粉章鱼,**结构完全不同**。
> **核心原则**: 视频质量保证 = 明确的"多少秒到多少秒具体做什么",**不能笼统地给大模型发挥空间**。
> **配套文档**:
> - `docs/v2-pipeline.md` — 8 步管线流程 (从角色基准到部署到 V2 桌宠)
> - `prompts/00-format.md` — 4 段段落格式规格 (用于 V2 动作 prompt 组装)

---

## TL;DR — 3 个必含

1. **通用前缀** (每个 prompt 必加, 全部约束)
2. **动作三段式**: 动作概述 + 按秒分割 + 动作结束后状态
3. **时间戳 + 比例数字化** (e.g. `0~2秒`, `画幅宽度 8%-10%`, `距顶 10% 绿色`)

---

## 1. 通用前缀 (Universal Prefix)

每个 prompt 必含,确保 14 个动作之间**视觉一致** + **物理安全**:

> **【绝对空间与边界约束】**
> - **比例**: 16:9, 背景必须为纯绿幕 `#00FF00` (标准 Chroma Key), 无阴影/杂物/渐变/边框。
> - **章鱼位置 (V2 章鱼)**: 头顶在画幅垂直方向 ~20%, 触手触地点在 ~85%, 左右 25%-75%。
> - **缓冲区 (防裁切)**: 头顶距画幅顶边 ≥15% 画幅高度, 触手触地点距底边 ≥10%, 左右两侧 ≥10% 画幅宽度。
> - **禁止出界**: 圆耳小凸起/触手尖/吸盘绝不超出画幅边缘。
> - **触手锁死原点**: 8 触手全部触地点不发生 X/Y 平移, 仅允许轴心旋转 + 原地跳跃 + 触手微动 (触手尖上下抬 ≤ 5% 画幅高度, 触手整体微曲 ≤ 10°)。
> - **首末帧约束**: 第一帧 = 最后一帧 = 标准姿态 (3/4 跪坐, 8 触手前向, 头顶 2 圆耳小凸起, 双眼全睁, 表情温和, 微微腮红)。**无任何变出物体残留**。
> - **背景色值一致**: 14 个视频之间绿色 `#00FF00` 必须完全一致 (无色差)。

### 1.1 dsh-pet → V2 章鱼 角色词汇翻译表

**关键教训**: V2 章鱼跟 dsh-pet 的 Q版蓝发女仆**结构完全不同**, 通用前缀和描述必须**全部翻译**。直接抄 dsh-pet 原文会导致"双脚锁死 (章鱼没脚)" / "呆毛 (章鱼没呆毛)" / "双手举 (章鱼没手)" 等错误。

| dsh-pet 角色专属 | V2 章鱼对应 | 备注 |
|------------------|--------------|------|
| 双手 / 双脚 | 触手 (8 条) | 章鱼核心肢体 |
| 双脚落点 | 8 触手落点中心 | 章鱼 8 个触地点 |
| 呆毛 (单根) | 圆耳小凸起 (2 个对称) | 章鱼天然耳触手 |
| 裙摆 / 荷叶边围裙 | 无 | V2 极简原则 |
| 鲸鱼尾巴 (单根) | 触手 (多根, 整体可动) | 章鱼尾巴就是触手 |
| 鞋 / 脚跟踮起 | 触手触地点 | 章鱼没鞋 |
| 双手举 / 双手叉腰 / 双手合十 | 触手举 / 触手卷 / 多触手合 | 动词需改 |
| 头部转动 | 头部转动 (章鱼也有头部) | 中性通用 |
| 眼睛 / 表情 / 腮红 | 眼睛 / 表情 / 腮红 | 通用 |

**强制检查**: 每个 prompt 提交前必须 grep 检查, **没有 "双手/双脚/呆毛/裙摆/鲸鱼尾巴/鞋/围裙"** 等 dsh-pet 角色专属词。

## 2. 动作三段式 (3-Section Structure)

### A. 动作概述 (Action Overview)

1-2 句话, 必含:
- 这个动作是什么 (e.g. "原地站立, 周期性眨眼, 圆耳随呼吸微动")
- **强调"原地" + "触手锚定原点" + "全程不位移"**
- 核心元素清单 (变出的物体/消失的物体)

### B. 按秒分割画面 (Per-Second Breakdown)

**3-5 段, 每段 1.5-3.5 秒**, 累计 10 秒。每段必含 5 个元素:

| 元素 | 作用 | 例子 |
|------|------|------|
| 1. 起始状态 | 接续上段 | "标准 3/4 跪坐" / "触手已举起" |
| 2. 具体动作 | 这段做啥 | "轻轻眨眼 / 抬起右触手 / 身体微微下沉" |
| 3. 关键细节 | 比例/位置/表情 | "表情满足 / 触手弯曲 30° / 距画幅顶边 5%" |
| 4. ⚠️ 强调 | 物理/空间/防穿模 | "⚠️ 强调: 触手尖仍距底边 10% 绿色空间" |
| 5. 空间坐标 | 数字化位置 | "头顶上方 30% 位置" / "画幅宽度 8%-10%" |

### C. 动作结束后状态 (Post-action State)

**固定模板**,列出必须清除的物体:

> **最终帧**: 与第一帧标准 3/4 跪坐姿态完全一致——8 触手自然前向, 头顶 2 圆耳小凸起, 双眼全睁, 表情温和, 微微腮红, 触手尖稳定接地。**无[物品]残留**。

每个动作的"无[物品]残留"必须列出该动作变出/消失的所有物体。

## 3. 时间戳写法 (Timestamp Rules)

| 模式 | 用途 | 例子 |
|------|------|------|
| `0~2秒` | 阶段标题 (短段) | "变出物品" |
| `2~4秒` | 阶段标题 (中段) | "举高展示" |
| `4~6.5秒` | 阶段标题 (中长) | "使用物品" |
| `6.5~8.5秒` | 阶段标题 (中) | "收回/放下" |
| `8.5~10秒` | 阶段标题 (收尾) | "消失 + 恢复" |

**时长自适应**:
- 简单动作 3-4 段足够 (e.g. "待机呼吸")
- 复杂动作 5 段 (e.g. "放风筝" 含 变出-抛起-牵引-收线-消失)
- 总时长 10 秒, 不超出, 不短于 6 秒

## 4. 数字化比例 (Digital Proportions)

❌ **抽象描述** (大模型发挥空间大):
```
拿起一个盘子, 不大不小
```

✅ **数字化 + 比例锚定** (大模型无歧义):
```
触手从身前凭空变出一个圆盘 (直径约 8% 画幅宽度, 距画幅底边 5% 绿色空间)
```

### 常用比例词汇

| 类别 | 词汇 |
|------|------|
| 画幅空间 | 距画幅顶/底/左/右 [N]% 绿色空间 |
| 物品大小 | 直径约 [N]% 画幅宽度 / 高度约 [N]% 画幅高度 |
| 相对比例 | 约人物手掌 [N] 倍 / 约触手尖 [N] 倍 |
| 表情幅度 | 嘴角上扬 5° / 眼睛眯成弯月 30% 闭合 |
| 移动幅度 | 身体倾斜 ≤10° / 轴心旋转 ≤90° |
| 跳跃高度 | 跳跃高度 ≤ 画幅高度的 10% |
| 频次节奏 | 眨眼每隔 1-2 秒 / 喘息每 2 秒 1 次 |

---

## 5. ⚠️ 强调标记 (Warning Markers)

关键约束/陷阱**必须**用 ⚠️ 标记, **降低大模型忽略概率**:

- ⚠️ 强调: 触手尖仍距画幅底边 ≥10% 绿色空间
- ⚠️ 强调: 圆耳小凸起不超画幅顶边
- ⚠️ 强调: 物品比例 Q 版, 不超过触手范围
- ⚠️ 强调: 物理合理性 (茶水不洒 / 火花不落地)
- ⚠️ 强调: 与前段动作连贯, 不出现"瞬移"或"穿模"

## 8. 关键陷阱 (Common Pitfalls)

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| "自然演变" (无明确动作) | "2~4秒: 触手轻抬 30° 至胸前" |
| "很小的物品" (无尺寸) | "直径约 5% 画幅宽度" |
| "表情自然" (无具体) | "眼睛微眯成弯月, 嘴巴微张" |
| 抽象动词 (e.g. "做点什么") | 具体动词 (e.g. "左触手夹起" / "右触手托住") |
| 时间留空给大模型 | 5 段时间戳填满, 不留 1 秒空白 |
| 物品出现没说明消失 | 段尾 + 动作结束后状态双重清场 |
| 角色 X/Y 移动 | 明确写"原地", "触手锁死原点", "轴心旋转" |
| 道具超界 (触手超底/顶) | ⚠️ 强调缓冲区约束 |

## 9. 使用方法

1. **写动作概述**: 1-2 句, 列出核心元素 + 强调"原地"
2. **拆 3-5 段**: 每段 1.5-3.5s, 凑足 10s
3. **每段写 5 元素**: 起始 + 动作 + 细节 + ⚠️ 强调 + 空间
4. **套动作结束后状态**: 列出所有消失物体
5. **合通用前缀**: 复制粘贴到 prompt 顶部
6. **进 V2 14 动作文件**: 每个动作单独文件, 用模板 (00-template.md)
